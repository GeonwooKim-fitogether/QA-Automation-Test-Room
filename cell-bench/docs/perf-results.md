# 성능 결과 파일 — 동적 시험이 남기고 결과판이 읽는 약속

> 한 줄 요지: **동적 시험의 성능 결과는 비교 도구 `tools/compare_motion_cell.py` 가 `data/` 에 남기는 `compare_<모터 기록 이름>.csv` 한 장이다.** 결과판의 성능 화면은 이 파일만 읽는다. 모터 엔진과 결과판은 서로를 부르지 않고 이 파일로만 이어진다.

이 문서는 새 형식을 정하지 않는다. 비교 도구가 이미 쓰고 있는 파일을 정본으로 굳히고, 결과판이 그중 무엇을 읽는지 적는다. 비교 도구가 칸 이름을 바꾸면 이 문서와 `serve_board.py` 의 `perf_runs` · `tests/test_board_perf.py` 를 같은 PR 에서 고친다.

## 1. 누가 쓰고 누가 읽나

| | 무엇 | 언제 |
|---|---|---|
| 쓰는 쪽 | `tools/compare_motion_cell.py` | 지금은 사람이 시험 뒤 손으로 돌린다. 사이클 엔진의 "방전하는 동안 할 일" 자리가 생기면 사이클마다 자동으로 돈다(계획) |
| 읽는 쪽 | `serve_board.py` 의 `/api/perf` → 결과판 `#perf` 화면 | 화면을 열 때와 10초마다 |

## 2. 파일 자리와 이름

- 자리: `data/compare_<모터 기록 이름>.csv` — `data/` 바로 아래만 읽는다. 같은 이름의 `.md` 는 사람용 보고서다.
- 이름 안의 `YYYYMMDD-HHMMSS` 가 그 시험의 시각이다. 예: `compare_motion_m2_20261027-104053.csv` 는 2026-10-27 10:40:53 모터 기록의 비교다. 시각이 없는 이름은 파일 수정 시각을 쓴다.
- 인코딩은 BOM 이 붙은 UTF-8(`utf-8-sig`), 첫 줄이 칸 이름이다.

## 3. 줄의 종류와 결과판이 읽는 칸

한 줄은 셀 하나 또는 IMU 파일 하나다. `kind` 칸으로 가른다. 비어 있는 칸은 그 값이 없다는 뜻이다(예: GPS fix 가 없으면 오차 칸이 빈다).

**`kind = cell` — 셀 라이브 속도 비교**

| 칸 | 뜻 | 단위 |
|---|---|---|
| `cell` | 셀 시리얼 | — |
| `packets` | 받은 라이브 패킷 수 | 개 |
| `fix` | GPS fix 모드별 패킷 수, 예 `N:120 A:30` | — |
| `sats` · `cn0` | 사용 위성 수 평균 · 평균 신호 세기 | 개 · dBHz |
| `status` | 정렬 판정 (4절) | — |
| `lag_A_s` | 셀 시각 − 모터 시각 (첫 동기 창) | 초 |
| `r_A` | 첫 동기 창의 상관 계수 | — |
| `hist_k` | 셀 속도 ÷ 모터 속도 배율. 1 근처면 단위 가정이 맞다 | — |
| `hist_rms` · `hist_p95` · `hist_max` | 셀 속도 이력 − 모터 속도의 RMS · \|오차\| 95% · 최대 | mm/s |

**`kind = imu` — 추출한 IMU 가속도 비교**

| 칸 | 뜻 | 단위 |
|---|---|---|
| `file` | IMU CSV 파일 이름 | — |
| `axis` | 모터 축과 가장 잘 맞은 IMU 축 | — |
| `status` · `lag_A_s` · `r_A` | 위와 같다 | |
| `acc_k` | 배율 | — |
| `acc_rms` · `acc_p95` · `acc_max` | IMU 가속도 − 모터 가속도 | mm/s² |

그 밖의 칸(`lag_B_s`, `drift_ppm`, `hspeed_*` 등)은 파일에 있지만 결과판은 읽지 않는다. 자세한 뜻은 같은 이름의 `.md` 보고서 끝 '가정 · 판정 기준' 에 있다.

## 4. `status` 의 값

| 값 | 뜻 |
|---|---|
| 정렬됨 | 모든 동기 창에서 상관이 0.5 이상 — 오차를 믿어도 된다 |
| 약함 | 상관은 낮지만 첫 창과 마지막 창의 시각 차이가 0.05초 안에서 같다 |
| 정렬 불가 | 시각을 맞추지 못했다 — 오차 칸이 빈다 |
| fix 없음 | 기록 내내 GPS fix 가 없었다 (실내라면 예상된 결과) |
| 모터 정지 | 모터가 움직이지 않아 맞출 동기 이동이 없다 |
| IMU 표본 없음 | IMU 파일에 읽을 표본이 없다 |

문턱 0.5 · 0.05초는 비교 도구의 제안값이다(`motionbench/align.py` 의 `quality`).

## 5. 합격선은 아직 없다

**결과판은 이 숫자에 빨강 · 초록을 붙이지 않는다.** 얼마면 합격인지 정해진 기준이 없기 때문이다. 화면은 숫자와 `status` 만 보여 주고, 기준이 정해지면 그 기준과 출처를 [동적 시험 기준 문서](../../dynamic-bench/README.md) 에 먼저 적은 뒤 화면에 붙인다.
