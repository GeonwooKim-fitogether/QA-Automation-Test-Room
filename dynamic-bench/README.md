**매뉴얼로 확인한 것**

| 항목 | 내용 | 출처 |
|---|---|---|
| 앞면 "--" (오른쪽 점 없음) | 주전원 꺼짐 또는 EtherCAT Init. "--" + 오른쪽 점 = PreOP 이상 · 서보 꺼짐 | `[매뉴얼 SX-DSV03241 p.35]` |
| Err80.4 (0x603F = 0xFF50 와 함께 나옴 `[실측]`) | PDO watchdog error protection — OP 중 상위에서 오는 PDO 가 정해진 시간 안에 안 옴. 해제 가능 알람. 조치: PDO 송신이 멈추지 않는지, 케이블 배선 · 노이즈 확인 | `[매뉴얼 SX-DSV03242 p.292]` |

**아직 매뉴얼로 확인하지 않은 것** — 확인되면 쪽수와 함께 아래 표에 옮긴다.

| 확인할 것 | 왜 필요한가 |
|---|---|
| 0x60FD 디지털 입력의 비트 배치 | 레일 끝 센서가 드라이브에 들어오는지 보려면 비트 뜻이 필요 |
| 0x607E Polarity · Pr3.26 의 뜻 | 방향 설정이 무엇인지 |
| Pr5.13 과속도 레벨의 단위 (읽은 값 7400) | 속도 상한을 정하려면 단위가 필요 |
| 0x6007 = 1 · 0x605E = 2 · 0x605A = 2 의 뜻 | 통신 두절 · 알람 · Quick stop 때 드라이브가 어떻게 서는지 |
| 첫 서보 온 때 명령 없이 1.4~1.6 mm 움직이는 동작의 이름과 조건 | 아래 4절 실측. 원인은 매뉴얼로만 적는다 |
