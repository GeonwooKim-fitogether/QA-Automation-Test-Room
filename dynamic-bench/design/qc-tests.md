# 셀 QC 시험 목록

> **문서 판 1.1 · 2026-11-10**
> 레일 QC 의 시험 이름 · 절차 · 합격 기준을 이 문서 하나에 모은다. 시험은 고유 ID 로 부르고, 합격 기준은 시험마다 판 번호를 붙여 고쳐 나간다.
> 장비 조작 · 결과 파일 약속의 세부는 [프로토콜 v4](qc-protocol-v4.md)가 그대로 맡는다. v4 의 "파트 A · B · C" 는 이 문서의 ID 와 아래 표처럼 대응한다.

## 1. 시험 다섯 가지

ID 의 앞 단어는 **판정 대상**이자 **불합격이면 볼 곳**이다.

| ID | 시험 이름 | 판정 대상 | 불합격이면 볼 곳 | 모터 | v4 의 이름 | 검증 상태 |
|---|---|---|---|---|---|---|
| **GNSS-1** | GNSS 수신 시험 | GNSS 센서 출력 | 안테나 · 수신 회로 | 없음 | 파트 A | 검증 중 |
| **IMU-1** | IMU 정지 시험 | IMU 센서 출력 | IMU 칩 · 보정값 | 없음 | (새로) | 검증 중 |
| **IMU-2** | IMU 레일 시험 | IMU 센서 출력 | IMU 칩 · 보정값 | 있음 | 파트 C 의 IMU 항목 | 가설 |
| **FIRMWARE-1** | 움직임 판단 시험 | 펌웨어 산출값 | 펌웨어의 움직임 판단 | 있음 | 파트 C 의 움직임 판단 항목 | 가설 |
| **FIRMWARE-2** | 속도 · 거리 시험 | 펌웨어 산출값 | 펌웨어의 속도 거르기 | 있음 | 파트 B | 가설 |

- **센서 출력**: 센서 칩이 낸 값 그대로(셀 저장 기록의 GNSS 원래 속도 · 위치 · 신호 세기, IMU 가속도 · 각속도).
- **펌웨어 산출값**: 셀 펌웨어가 센서 출력으로 계산한 값(움직임 판단, 거른 속도, 그 속도로 계산한 거리). Live 앱이 따로 계산하는 거리는 이 목록의 대상이 아니다.
- IMU-2 와 FIRMWARE-1 은 **같은 레일 운전 한 번**으로 함께 판정한다.

**검증 상태 세 단계**

| 상태 | 뜻 |
|---|---|
| 가설 | 절차와 기준을 글로 세웠고 아직 실측으로 확인하지 않았다 |
| 검증 중 | 정상 셀로 절차가 재현되는 것을 확인했고, 불량 셀을 잡아내는지(검출력)가 남았다 |
| 확정 | 정상 셀의 반복성과 불량 셀 검출을 모두 실측으로 확인했다 |

## 2. 공통 조건

- **세트**: 같은 구성의 셀 묶음(예: Y 세트 = CLBY-4B 23대). 한 시험 기록에는 세트 · 셀 펌웨어 판 · 독 배치를 남긴다.
- **배터리로 시험한다**: 독 플러그를 끄고 돌린다. 충전은 시험 사이에만 한다(2026-11-02 결정).
- **위성 신호**: 실내 GNSS 시뮬레이터 LabSat 3 의 장면을 독 쪽으로 방사한다. 시험실 GPS 중계기는 끈다.
- **슬롯**: 독의 셀 자리. GNSS 는 슬롯마다 받는 신호가 달라 셀 효과와 슬롯 효과를 나눠야 한다(GNSS-1). IMU 는 슬롯 효과가 없다(IMU-1 첫 실측).
- **셀 기록 받기**: 시험이 끝나면 셀 저장 기록을 받으면서 셀에서 비운다.

## 3. 시험별 내용

### GNSS-1 · GNSS 수신 시험

| 칸 | 내용 |
|---|---|
| 잡으려는 불량 | 안테나 · 수신 회로 불량으로 같은 신호를 약하게 받는 셀 |
| 조건 | LabSat 정지 장면 `S01-Static-GLE-8h`, 출력 감쇠 **18 dB**(정상 셀이 겨우 위치를 유지하는 세기 — 0 dB 에서는 신호가 너무 세 셀 차이가 안 보인다), 독은 시뮬레이터 안테나를 바라보게 둔다 |
| 절차 | ① 들리는 셀 전부 원격 재부팅 ② 20대 이상 위치를 잡을 때까지 대기(최대 15분) ③ 5분 버림 ④ **30분 기록** ⑤ 감쇠 0 으로 되돌림 ⑥ 셀 기록 받기. 슬롯을 바꿔 **3회** 반복(배치 Y · Y-swap · Y-shift) |
| 판정 항목 | 셀마다 30분 구간의 신호 세기 중앙값(C/N0, 반송파 대 잡음 밀도비, dB-Hz). 위치를 못 잡은 회차 수 |
| 판정 방법 | 신호 세기 = 셀 효과 + 슬롯 효과 + 회차 효과 로 놓고 최소제곱으로 나눈다. **셀 효과로만** 합불을 본다. (슬롯 평균을 단순히 빼면 슬롯당 셀이 3대뿐이라 흔들려 오판한다 — 11-09 실측) |
| 합격 기준 **0.1** | 셀 효과 −3 dB 이하면 불량 후보. 3회 중 2회 이상 위치를 못 잡고 같은 슬롯의 다른 셀은 잡았으면 불량 후보 |
| 슬롯 점검 | 한 슬롯에 들어간 셀이 모두 위치를 못 잡으면 **불량 슬롯** — 그 슬롯은 시험에서 뺀다 |
| 근거 기록 | 2026-11-09 Y 세트 23대 3회(`cell-bench/data/collectA_20261109/`): 셀 효과 −1.9 ~ +2.0 dB, 같은 셀 반복 흔들림 1.9 dB → 불량 셀 없음. 슬롯 효과 −7.0 ~ +5.7 dB. **독 3열 2줄 슬롯은 세 셀 모두 위치를 못 잡아 불량 슬롯** |
| 남은 것 | 불량 셀 검출 증명 — 안테나 불량으로 알려진 셀이나 일부러 손상한 셀이 필요하다. 알루미늄 호일로 가린 셀은 신호가 1 dB 밖에 줄지 않아 시료가 되지 못했다 |

### IMU-1 · IMU 정지 시험

| 칸 | 내용 |
|---|---|
| 잡으려는 불량 | 가만히 있어도 회전이나 기울기를 잘못 재는 IMU — 자이로스코프 영점 오차, 가속도계 감도 · 영점 오차 |
| 조건 | 셀을 독에 둔 채 정지, 모터 없음. 슬롯은 아무 배치나 된다 |
| 절차 | 원격 재부팅을 **6번** 한다. 부팅마다 3분 안정 뒤 **5분 기록**. 끝나면 셀 기록 받기 |
| 판정 항목 | 부팅마다 ① 중력 크기(0.1초 평균 가속도 세 축의 크기, 중앙값, g) ② 자이로스코프 영점 오차(각속도 세 축 각각의 중앙값으로 만든 크기, °/s) |
| 판정 방법 | 셀마다 부팅별 값을 나란히 본다. 슬롯 효과가 없어 분해하지 않는다. 간헐 불량이 있으므로 **한 번이라도** 벗어나면 잡는다 |
| 합격 기준 **0.1** | 자이로스코프 영점 오차가 한 부팅이라도 **2 °/s 초과**면 불합격 후보(정상 셀 최대 0.9 °/s 의 두 배). 중력 크기는 **기준 미정** — IMU 칩 데이터시트의 감도 · 영점 허용차를 확인한 뒤 정한다 |
| 단위 가정 | 가속도 1 g = 2048, 각속도 1 °/s = 16.4 (±16 g · ±2000 °/s 범위 가정, 데이터시트 미확인) |
| 근거 기록 | ① 2026-11-09 GNSS-1 3회 기록을 다시 읽음(Y 22대, `collectA_20261109/imu_items.json`): 같은 셀은 슬롯이 바뀌어도 중력 크기 차 0.0015 g 이하, 자이로스코프 영점 오차 차 0.33 °/s 이하. 정상 셀 영점 오차 0.1 ~ 0.9 °/s. **10695 는 z 축 9.8 · 8.6 · 0.1 °/s — 3회 중 2회만 나타났다**. 중력 크기는 셀마다 0.969 ~ 1.024 g 로 고정된 셀 고유값 ② 2026-11-10 이 절차대로 처음 시험(Y 23대, 배터리, `imuStill_20261110/imu_items.json`): **23대 모두 6번 다 2 °/s 이하**(최대 0.88 °/s). 같은 셀의 부팅 사이 차는 중력 0.0005 g · 영점 0.06 °/s 이하. **10695 는 6번 모두 0.09 ~ 0.14 °/s 로 정상** — 어제의 큰 값이 오늘은 한 번도 나오지 않았다 |
| 남은 것 | 10695 의 큰 영점 오차가 무엇에서 나오는지(어제와 오늘의 차이: 감쇠 · 재부팅 사이 간격 · 기록 길이 30분 대 5분). 부팅 6번으로는 이 간헐 불량을 잡지 못했으므로 절차의 검출력이 확인되지 않았다. 데이터시트로 중력 크기 기준 |

### IMU-2 · IMU 레일 시험

| 칸 | 내용 |
|---|---|
| 잡으려는 불량 | 움직일 때 가속도를 틀리게 재는 IMU |
| 조건 | 레일 150 ↔ 750 mm 왕복, 속도 100 mm/s, 왕복 3번 · 끝 멈춤 5초를 한 번으로 두 가속도를 운전한다 — 50 mm/s²(승인 프리셋 `long-C`)와 500 mm/s²(승인 프리셋 `long-C500`, 2026-11-10 추가). LabSat 정지 장면 |
| 한 번 가기의 모양 | 가속도 지령은 사다리꼴 속도다 — 50 mm/s² 는 가속 2초 · 등속 4초 · 감속 2초, 500 mm/s² 는 가속 0.2초 · 등속 5.8초 · 감속 0.2초. 운전 한 번에 출발 6번 · 정지 6번이 나온다 |
| 판정 항목 | 레일 방향 축 가속도를 적분한 **속도 변화 ÷ 모터 속도 변화**를 **출발 구간과 감속 구간 따로** 낸다 |
| 판정 방법 | 레일 방향 축은 움직일 때 남는 가속도의 주된 방향으로 고른다. 출발 구간은 바로 앞 멈춤을, 감속 구간은 바로 앞 등속 구간(실제 가속도 0)을 영점으로 빼고 적분한다. 구간 끝은 정지 뒤 0.5초로 잘라 출렁임을 덜 섞는다. 0.1초 평균값은 적분에는 손실이 없으므로 그대로 쓴다. 셀 시각과 모터 시각은 출발 가장자리로 맞춘다. 0.01초 순간값을 직접 맞대는 방식은 모터 진동에 묻혀 셀을 가르지 못했다(11-09: 상관 0.53 ~ 0.59) — 쓰지 않는다 |
| 감속 구간을 넣는 이유 | 비교 자료가 두 배가 되고, 한 방향만 덜 재는 불량을 잡는다. 처음 설계(프로토콜 v4)에는 출발 구간만 있었고 감속을 뺀 이유는 적혀 있지 않다 |
| 신호 크기 | 속도 변화가 0.1 m/s 뿐이라 50 mm/s² 의 가속도는 센서 눈금 약 10칸이다. 영점이 1칸 틀리면 비율이 약 10 % 흔들린다. 500 mm/s² 가 같은 오차에 약 2.5배 강하다. 더 키우려면 속도를 올려야 하고, 그때는 이동 거리(지금 600 mm, 레일 사용 가능 약 1,768 mm)를 늘려야 한다 |
| 합격 기준 **0.1** | 속도 변화 비 0.85 ~ 1.15 (프로토콜 v4 의 `imu` 제안값) |
| 근거 기록 | 2026-10-29 프로토콜 v1 1차: 22대 0.9 ~ 1.1(중앙 0.99), **10696 만 0.02 ~ 0.75** — 불량 후보(꽂힘 상태 미확인) |
| 남은 것 | 판정 도구(출발 · 감속), 첫 실측 |

### FIRMWARE-1 · 움직임 판단 시험

| 칸 | 내용 |
|---|---|
| 잡으려는 불량 | 움직임을 늦게 알아채거나, 움직이는데 멈춤으로 판단하거나, 멈춰 있는데 움직임으로 판단하는 셀 |
| 조건 | IMU-2 와 같은 운전 |
| 판정 항목 | 출발 뒤 켜지기까지(초), **감속이 시작된 뒤 꺼지기까지(초)**, 움직이는 동안 켜져 있던 비율(%), 멈춰 있는 동안 잘못 켜짐(%) |
| 펌웨어 규칙 | 가속도 크기의 표준편차가 7.0 을 넘으면 움직임으로 판단한다 |
| 합격 기준 **0.1** | 미정 — 첫 실측 뒤 정한다 |
| 근거 기록 | 2026-10-30(Y, 정지 장면): 가속도 50 mm/s² 에서 켜지기까지 0.78초(0.48 ~ 1.28), 켜져 있던 비율 97.7%(88.1 ~ 99.7). 500 mm/s² 에서 0.23초 · 100%. 멈춰 있는 동안 잘못 켜짐 0% |
| 꺼지기까지를 재는 기준점 | 처음에는 멈춘 시각부터 쟀는데, 천천히 멈추면(50 mm/s²) 다 서기 전에 판단이 먼저 꺼져 24대 모두 0.08초로 나왔다(2026-10-30). 그래서 **감속이 시작된 시각부터** 잰다 |
| 남은 것 | 판정 도구에 감속 시작 기준 꺼짐 시간 넣기, 첫 실측 |

### FIRMWARE-2 · 속도 · 거리 시험

| 칸 | 내용 |
|---|---|
| 잡으려는 불량 | 거른 속도와 그 속도로 계산한 거리가 실제 움직임과 다른 셀 |
| 조건 | 레일 운전과 같은 속도로 움직이는 LabSat 장면을 함께 튼다(300 · 100 · 500 mm/s, 장면 `S03_RailB120` · `S04_RailB100` · `S05_RailB500`, 승인 프리셋 `long-B` · `long-B100` · `long-B500`), 속도마다 10번 |
| 판정 항목 | 거른 속도 ÷ 모터 속도, 거른 속도로 계산한 거리 ÷ 1,500 mm, 위치로 잰 거리 ÷ 1,500 mm |
| 합격 기준 **0.1** | 미정 — 판정 항목 이름은 프로토콜 v4 §4 의 `gps_move` 를 따른다 |
| 남은 것 | 1차 기준 파일 `cell-bench/motionbench/criteria/rail_v1.json`(2026-11-02)과의 관계 정리 |
