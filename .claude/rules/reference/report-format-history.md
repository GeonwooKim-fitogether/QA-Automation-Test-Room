# 보고 양식 규칙 · 부록: 태어난 사고

> 이 파일은 [`../report-format.md`](../report-format.md)의 부록이다. 규범은 코어 파일에 전부 있고, 여기에는 규칙이 태어난 사고와 장치를 그렇게 만든 이유만 있다. 자동 로드되지 않는다.

## 무슨 일이 있었나 (2026-11-13, 레일 QC 보고서)

하드웨어 팀의 셀 QC 시험 현황 보고서를 하루 동안 고치면서, 사용자가 같은 지적을 여러 번 되풀이했다.

| 지적 | 실제로 일어난 일 |
|---|---|
| 틀을 지켜라 | 고칠 때마다 표를 새로 만들어, 앞에서 합의한 칸이 사라졌다 |
| 칸에 문장을 쓰지 마라 | 칸에 설명 · 경위 · 괄호 해설이 들어가 한눈에 읽히지 않았다 |
| 정한 말을 써라 | `원값` · `조합` · `모터 없음` · `판` · `정본` 처럼 정하지 않은 말을 지어내거나, 정한 이름을 풀어 쓰고 바꿔 불렀다 |
| 문서에서 읽어라 | 시험 조건 · 절차 · 합격 기준을 시험 문서에서 읽지 않고 기억으로 다시 써서 문서와 달라졌다 |
| 합의와 진행을 나눠라 | 사용자와 합의만 된 것과 시험까지 끝난 것이 같은 상태로 보여, 어디까지 왔는지 맞출 수 없었다 |
| 하나씩 끝내라 | 미완료를 남긴 채 다른 시험 · 다른 화면을 손대 시작 지점을 찾을 수 없었다 |

그 결과 3시간 넘게 장비 운전이 0회였다. 보고를 고치는 일이 시험을 진행하는 일을 대신해 버렸다.

## 왜 글이 아니라 장치인가

같은 원칙은 그전에도 메모리와 스킬(`ceo-brief` 3-3절)에 글로 있었다. 글은 읽혀야 작동하는데, 새 세션은 규칙을 읽고도 정한 말 대신 자기 말을 썼고, 표를 낼 때 앞의 틀과 대조하지 않았다. 지적이 반복된 것은 원칙이 없어서가 아니라 **원칙을 어겨도 아무것도 멈추지 않았기 때문**이다.

그래서 사용자는 세 가지를 장치로 강제하길 원했다.

1. **용어 통일.** 금지한 말을 쓰려는 순간 훅이 막고 대신 쓸 말을 알린다(`terms-guard.py`). 금지어는 저장소마다 다르므로 규칙이 아니라 저장소의 용어표에 둔다. 구조는 폐기 목록(`retired.json` 과 `retired-guard.py`)을 따랐다. 목록이 없는 저장소에서는 아무 일도 하지 않으므로 도입 비용이 없다.
2. **모듈화.** 조건을 모듈로 나눈 표는 양식 파일의 `columns` · `categories` 로 고정한다. 칸이 바뀌면 훅이 막는다.
3. **보고 양식.** 표에 양식 이름과 버전을 붙이게 하고, 훅이 양식 파일과 대조한다(`report-format-guard.py`). 양식은 합의해야 생기고 합의해야 바뀌며, 변경이 PR 로만 일어나므로 사람의 머지 승인을 거친다.

## 왜 `none` 표시를 두었나

양식 폴더가 있는 저장소에서도 보고가 아닌 표(부록의 원자료, 설정 목록)를 아티팩트로 낼 일이 있다. 그런 표까지 막으면 관계없는 작업이 멈추고, 결국 사람이 훅을 꺼 버린다(DB 쓰기 훅의 셸 감시면이 확실한 경우에만 막는 것과 같은 이유). 그래서 `data-report-format="none"` 을 출구로 두고, 그것이 사람의 정직에 기댄다는 사실을 코어 4절에 적었다.
