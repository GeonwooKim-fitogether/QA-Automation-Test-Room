# 기획 v3 추가 지시 (2026-10-22, 김건우) — 셀 종류 자동 인식

방금 쓴 `dynamic-bench/plan/plan-v3.md` 에 아래 요구를 반영해 **같은 파일을 고친다** (새 버전 파일을 만들지 않는다). v1·v2 는 그대로. `dynamic-bench/` 밖은 수정 금지. 다른 세션(M1 개발)의 파일(`cell-bench/motionbench/`, `cell-bench/run_motion.py`, `cell-bench/tests/` 의 새 파일, `dynamic-bench/dev/`, `dynamic-bench/records/2026-10-22-m1.md`)은 건드리지 않는다.

## 사용자 요구
- 한 모듈에는 **Cell X 세트**(X5/X6, 도크 DKPX-1C) 또는 **Cell Y 세트**(Y1/Y3B/Y4, 도크 DKPY-1C) 중 하나가 실린다. X 와 Y 는 무게가 다르다.
- 세트가 연결되면 시스템이 **어느 종류인지 자동으로 인식**하고(예: 라이브 패킷의 셀 시리얼/모델, 또는 도크 종류 — 실제로 어떤 신호로 구분 가능한지는 코드/펌웨어 근거로 확인하고, 모르면 `[확인 필요]`), **작업자 설정 없이** 스스로 설정한다:
  - 페이로드 기반 속도·가속 상한과 모션 프로파일 프리셋
  - 기대 양산 펌웨어 버전 (Y4 계열 = v0.99.71 확정; X5/Y1 계열 = 미확정 → 열린 항목)
  - 파서 변형(패킷 형식 차이가 있으면)
  - 종류별 합격 기준
- **세트는 절대 섞이지 않는다** (사용자 확인: 한 세트 = 한 셀 종류). 따라서 종류는 **세트 단위**로 인식한다. 혼재로 읽히면(X 와 Y 가 같이 보이면) 이는 **이상 상황**으로 취급한다 — 시작을 막고 작업자에게 경고한다 (오인식·배선·등록 오류 가능성).
- 질량: 도크 ~2.2 kg, 셀 개당 ~51–60 g (기록이 서로 안 맞음, Fitstack Specification 에서 재확인 중). 실측 전까지 **보수적 기본값 페이로드 5 kg** 를 쓴다. 이 값들은 `[확인 필요]` 로 표시.

## 반영 방식
- 결론 요약, 작업 흐름(A 모션 · C 시나리오 · D 파서 · E 작업자 UI 등)과 의존관계 도표, 열린 질문/결정 필요에 각각 반영. 종류 인식 → 설정 적용 흐름을 Mermaid 로 한 장.
- 지어내지 말 것. 근거 없는 수치는 `[제안값]`/`[확인 필요]`.
