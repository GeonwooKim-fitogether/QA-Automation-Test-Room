# 마이그레이션 폴더

데이터베이스 구조와 기준 데이터를 바꾸는 SQL 파일을 둔다.

## 파일명

새 파일은 UTC 생성 시각을 사용한다.

```text
YYYYMMDDHHMMSS_short_description.sql
```

예:

```text
20260918031500_add_user_country.sql
```

기존 순번 파일은 이름을 바꾸지 않는다.

## 작성 원칙

- 한 파일은 한 목적만 가진다.
- 운영 데이터 삭제와 구조 삭제를 같은 배포에 묶지 않는다.
- 큰 테이블의 잠금과 실행 시간을 검토한다.
- 가능한 경우 새 구조 추가 → 데이터 백필 → 읽기 전환 → 옛 구조 제거로 나눈다.
- local의 빈 DB에 처음부터 전체 파일을 적용할 수 있어야 한다.
- 운영 적용 전 DB 변경 요청서에 영향·백업·복구/forward-fix 계획을 기록한다.
